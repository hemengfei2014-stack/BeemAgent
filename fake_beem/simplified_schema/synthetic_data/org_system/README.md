# Organization System Synthetic Data

This directory contains scripts to generate, validate, and visualize synthetic data based on the simplified Organization System Schema.

## Directory Structure

*   **data/**: Contains the generated TSV data files (`org.txt`, `user.txt`, `dept.txt`, `dept_user.txt`).
*   **scripts/**: Python scripts for data generation and processing.
    *   `generate_org_data.py`: Generates the raw TSV data based on specific business rules (Jaco & Beem companies).
    *   `validate_data.py`: Validates the generated data against the schema constraints and business logic.
    *   `convert_data_to_json.py`: Converts the flat TSV files into a hierarchical JSON format (`org_data.json`) for the web visualization.
*   **web/**: A simple HTML/JS frontend to visualize the organization chart.
    *   `index.html`, `style.css`, `app.js`: Frontend source code.
    *   `org_data.json`: The data source used by the frontend (generated by `convert_data_to_json.py`).

## Relationship to Schema

The data generated here strictly adheres to the schema defined in `../org_system_schema_simplified.md`.
*   **Tables**: `org`, `user`, `dept`, `dept_user` match the schema definitions.
*   **Constraints**: Uniqueness, foreign keys, and field values (e.g., Roles 1-9) are enforced and validated.

## How to Generate and Validate Data

1.  **Generate Data**:
    Run the generation script to create new random data in `data/`:
    ```bash
    python3 scripts/generate_org_data.py
    ```

2.  **Validate Data**:
    Run the validation script to ensure data integrity and compliance with requirements:
    ```bash
    python3 scripts/validate_data.py
    ```

3.  **Prepare for Visualization**:
    Convert the raw data to JSON for the web app:
    ```bash
    python3 scripts/convert_data_to_json.py
    ```

## How to Start the Visualization Service

To view the Organization Chart:

1.  Navigate to the `web` directory:
    ```bash
    cd web
    ```
    (Or run from anywhere using the path to `web`)

2.  Start a Python HTTP server:
    ```bash
    python3 -m http.server 8081 --directory /root/hemengfei/beemagent/fake_beem/simplified_schema/synthetic_data/org_system/web
    ```

3.  Open your browser (or preview window) at `http://localhost:8081`.
