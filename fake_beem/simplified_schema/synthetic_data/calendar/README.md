# Calendar System Synthetic Data

This directory contains scripts to generate, and visualize synthetic data based on the simplified Calendar System Schema.

## Directory Structure

*   **data/**: Contains the generated TSV data files (`calendar_event.txt`).
*   **scripts/**: Python scripts for data generation and processing.
    *   `generate_calendar_data.py`: Generates the raw TSV data based on specific business rules (Jaco & Beem companies).
    *   `convert_data_to_json.py`: Converts the flat TSV files into a hierarchical JSON format (`calendar_data.json`) for the web visualization.
*   **web/**: A simple HTML/JS frontend to visualize the calendar events.
    *   `index.html`, `style.css`, `app.js`: Frontend source code.
    *   `calendar_data.json`: The data source used by the frontend (generated by `convert_data_to_json.py`).

## Relationship to Schema

The data generated here strictly adheres to the schema defined in `../../calendar.md`.
*   **Tables**: `calendar_event` matches the schema definitions.
*   **Constraints**: Uniqueness, foreign keys, and field values are enforced.

## How to Generate and Validate Data

1.  **Generate Data**:
    Run the generation script to create new random data in `data/`:
    ```bash
    python3 scripts/generate_calendar_data.py
    ```

2.  **Prepare for Visualization**:
    Convert the raw data to JSON for the web app:
    ```bash
    python3 scripts/convert_data_to_json.py
    ```

## How to Start the Visualization Service

To view the Calendar Events:

1.  Navigate to the `web` directory:
    ```bash
    cd web
    ```
    (Or run from anywhere using the path to `web`)

2.  Start a Python HTTP server:
    ```bash
    python3 -m http.server 8081 --directory /Users/hemengfei/company/work/beemagent/fake_beem/simplified_schema/synthetic_data/calendar/web
    ```

3.  Open your browser (or preview window) at `http://localhost:8081`.
