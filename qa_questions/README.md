# 第一部分：数据权限说明

## 多组织数据隔离

本数据集包含**多个独立组织**，不同组织间的数据**严格隔离**，互不可见：

| 组织ID | 组织名称 | 用户数 | 说明 |
|-------|---------|-------|------|
| 1 | **Jaco** | 61 | 当前用户所在组织 |
| 2 | **Beem** | 若干 | 独立组织，Jaco用户无权访问 |

**重要**：
- Jaco 组织的用户**只能访问** Jaco 组织的数据
- Beem 组织的数据对 Jaco 用户**完全不可见**
- 跨组织查询必须先明确组织上下文

## 各系统数据权限

| 系统 | 数据可见性 |
|:----:|:-----------|
| **组织系统** | 组织内公开（Jaco用户可查看所有Jaco员工和部门信息） |
| **消息系统** | 严格权限控制（只能访问自己参与的私聊和群聊会话） |
| **文档系统** | 严格权限控制（只能访问自己拥有或被共享的文档） |
| **日程系统** | 组织内公开（Jaco用户可查看所有Jaco员工的日历） |

# 第二部分：问题列表

## 1. 组织架构系统 - `org_qa.md`

**问题数量**: 390 条

**内容范围**:
- 公司基本信息（名称、CEO、成立时间、规模、部门数量）
- 个人资料查询（工号、职位、入职时间、联系方式、上级）
- 特定员工信息（以"贝冠"为例）查询
- 部门信息（名称、负责人、人数、上下级关系）
- 组织架构树、兄弟部门、下属列表
- 按角色/部门/姓名/手机号/邮箱搜索员工

**业务场景**: 企业 HR 管理系统、员工通讯录

**权限特点**: 组织内公开，员工可查看其他员工和部门信息

## 2. 即时通讯系统 - `im_qa.md`

**问题数量**: 298 条

**内容范围**:
- 最近沟通联系人与时间
- 发送/接收消息统计（今日/本周/本月）
- 与特定人（李世/萧翔/贝冠）的聊天记录
- 关键词搜索（抖音、快手、BGM、带货、短视频、算法、剪辑等）
- 文件/链接相关查询、共同群聊检查
- 群聊列表与活跃度统计

**业务场景**: 企业内部即时通讯工具，类似钉钉/企业微信

**权限特点**: 严格权限控制，只能访问参与的私聊和群聊会话

## 3. 文档协作系统 - `doc_qa.md`

**问题数量**: 460 条

**内容范围**:
- 可访问文档列表、权限查询
- 我创建/最近修改的文档
- 按文档类型统计（doc/sheet/slide/pdf）
- 标题/内容关键词搜索（MCN、网红、特效、带货、流量、算法等）
- 文档所有者/共享者查询
- 文档长度排序、创建时间筛选

**业务场景**: 企业文档协作平台，类似 Google Docs / 飞书文档

**权限特点**: 严格权限控制，只能访问自己拥有或被共享的文档

# 第四部分：使用说明

## 解答文件内容

每个解答文件包含：
1. **问题描述**: 对应的问题编号范围
2. **代码实现**: 完整的Python代码，包括数据加载、查询逻辑
3. **执行结果**: 实际运行输出的示例结果
4. **答案总结**: 问题的答案要点
5. **数据说明**: 相关的权限和数据特点说明

## 应用场景

这些问题列表及解答可用于：
- **训练数据**: 用于训练模型理解业务查询意图
- **测试评估**: 验证模型对各类业务问题的回答准确率
- **Prompt 工程**: 作为 few-shot 示例或系统提示的参考
- **数据生成**: 基于这些问题生成对应的 SQL/工具调用查询
- **参考实现**: 提供完整的查询代码实现，便于理解数据结构

## 文件格式

所有问题文件均采用统一的编号列表格式：
```
1. 问题文本
2. 问题文本
...
```
便于程序解析和处理。
