# 问题 1-12: 公司名称和CEO相关

## 问题描述
问题 1-12 都是询问公司名称或CEO：
1. 我们的公司全称叫什么？
2. 公司的正式名称是什么？
3. 咱们公司的全名是？
4. 公司的注册名是什么？
5. 查一下公司名。
6. 这里的组织名称叫什么？
7. 公司CEO是谁？
8. 咱们公司的老板是谁？
9. 谁是公司的最高负责人？
10. 公司的 Owner 是哪位？
11. 谁在管理整个公司？
12. 查一下 CEO 的名字。

## 解题思路
1. 当前用户所属组织是 Jaco（org_id=1）
2. 从 org 表获取公司名称
3. 从 org 表的 owner_user_id 字段获取CEO的用户ID，再到 user 表查询CEO姓名

## 代码实现

```python
from utils import loader, CURRENT_ORG_ID, get_current_org

# 获取当前组织信息
org = get_current_org()
print(f"组织ID: {org['id']}")
print(f"组织名称: {org['name']}")
print(f"组织简称: {org['short_name']}")
print(f"负责人用户ID: {org['owner_user_id']}")

# 获取CEO信息
ceo_user_id = org['owner_user_id']
ceo = loader.get_user_by_id(ceo_user_id)
print(f"\nCEO信息:")
print(f"姓名: {ceo['name']}")
print(f"工号: {ceo['id']}")
print(f"职位: {loader.get_role_name(ceo['role'])}")
```

## 执行结果

```

组织名称: Jaco
组织简称: Jaco
负责人用户ID: 10001

CEO信息:

职位: 一级部门leader
```

## 答案总结

**问题 1-6（公司名称）**: **Jaco**

**问题 7-12（CEO/老板）**: **马云**（工号：10001）
