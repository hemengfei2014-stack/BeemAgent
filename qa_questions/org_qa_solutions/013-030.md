# 问题 13-30: 公司成立时间、总部地址、员工总数

## 问题描述
问题 13-18: 公司成立时间相关
问题 19-24: 公司总部地址相关
问题 25-30: 公司员工总数相关

## 解题思路
1. 公司成立时间：从 org 表的 created_at 字段获取
2. 总部地址：查看数据表，没有地址字段，需要告知用户数据中没有此信息
3. 员工总数：统计 user 表中 org_id=1 的用户数量

## 代码实现

```python
from utils import loader, CURRENT_ORG_ID, get_current_org
from datetime import datetime

# ============ 公司成立时间 ============
org = get_current_org()
created_at = org['created_at']
created_date = loader.timestamp_to_date(created_at)
created_year = loader.timestamp_to_year(created_at)

print("=== 公司成立时间 ===")
print(f"成立时间戳: {created_at}")
print(f"成立日期: {created_date}")
print(f"成立年份: {created_year}")

# 计算公司成立多久了（从成立到现在）
current_time = datetime.now()
current_timestamp = int(current_time.timestamp())
years_diff = current_time.year - created_year
print(f"成立至今: {years_diff} 年")

# ============ 总部地址 ============
print("\n=== 总部地址 ===")
print("数据表中没有地址相关信息字段，无法提供总部地址。")

# ============ 员工总数 ============
print("\n=== 员工总数 ===")
users = loader.get_org_users(CURRENT_ORG_ID)
total_count = len(users)
print(f"Jaco组织员工总数: {total_count} 人")
```
